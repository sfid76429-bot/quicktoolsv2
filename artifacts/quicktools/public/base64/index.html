Base64 converter

Encode text to Base64 or turn Base64 back into readable Unicode. A useful helper for notes, payloads and debugging.

One small note

Base64 is an encoding, not encryption. Do not use it to protect secrets.

Unicode-safe Base64 in the browser

Base64 represents binary data with a compact set of ASCII characters. This converter first handles Unicode as UTF-8, so accented characters and many other scripts survive a round trip cleanly.

Use Encode for plain text and Decode for a Base64 string. Invalid input is reported instead of silently producing a misleading result.
