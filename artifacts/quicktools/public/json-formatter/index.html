Validate JSON as you edit

Paste an object or array into the editor and choose Format JSON to validate it and add two-space indentation. Minify removes formatting whitespace without changing the data. When parsing fails, the browser's error is preserved to help locate the problem.

JSON formatting is especially useful for API responses, configuration files and data handoffs. Keep private or sensitive content on your device by using this local tool.
