Make text consistent

Case conversion is useful after importing data, cleaning up a rough document or preparing headings for a page. Choose a conversion style to update the text in place, then copy the result wherever you need it.

QuickTools handles the conversion in your browser. It does not send pasted text to a server, so you can use it for private drafts and notes.
